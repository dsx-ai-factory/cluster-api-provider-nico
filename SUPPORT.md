# Support

## How to get help

| Channel | When to use |
|---|---|
| [GitHub Issues](https://github.com/dsx-ai-factory/cluster-api-provider-nico/issues) | Bug reports, feature requests, and documentation gaps |
| [GitHub Discussions](https://github.com/dsx-ai-factory/cluster-api-provider-nico/discussions/categories/q-a) | Questions, design proposals, and general Q&A |

## Before opening an issue

1. Search [existing issues](https://github.com/dsx-ai-factory/cluster-api-provider-nico/issues) to avoid duplicates.
2. Read the [documentation](docs/) and the [README](README.md).
3. Reproduce the problem on the latest commit of `main`.

## Security vulnerabilities

Do **not** open a public issue for a security vulnerability. Follow the process
in [SECURITY.md](SECURITY.md), which routes reports to NVIDIA PSIRT.

## Community

Contributions are welcome. [CONTRIBUTING.md](CONTRIBUTING.md) covers the
development environment, the commit conventions and how to open a pull request.
[GOVERNANCE.md](GOVERNANCE.md) describes how decisions are made and
[MAINTAINERS.md](MAINTAINERS.md) lists who makes them.

## NVIDIA enterprise support

For users running this as part of a supported NVIDIA product, contact your
NVIDIA support representative or visit the
[NVIDIA Support Portal](https://www.nvidia.com/en-us/support/).
